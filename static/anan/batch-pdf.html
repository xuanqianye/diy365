批量发布图解

两种来源：PDF 文件（逐页裁剪上传）或 图片文件夹（webp 等原图直传、不切片）。每个 PDF / 每个文件夹生成一篇草稿。提交后请到 草稿管理页 /anan/drafts.html 点「发布」或「全部发布」即可上线（推荐，直接改文件更可靠）。也可在 Decap 后台取消「草稿（不发布）」勾选，但后台的「已发布」状态可能显示不准。

统一设置（应用到每篇）
• 标题自动取 PDF 文件名 / 文件夹名（去扩展名，下划线/连字符转空格）；PDF 文件名序号保留，例如 0012_sunflower.pdf → 0012 sunflower；文件夹名里的批次编号会自动去掉，例如 001-sunflower → sunflower。
• 分类 / 标签建议填与「分类管理 / 标签管理」里已有的名称，前台才会出现对应聚合页；填新名称 Hugo 也会自动建页。
PDF 限制：每本 ≤ 100MB、≤ 100 页；长页会自动切片成多张图。每个 PDF 会变成若干张步骤图，第一张自动作封面。 处理在浏览器本地完成，可能耗时较久（页数多时请耐心等待，不要关闭页面）。可点「暂停」暂停当前批次，再点「继续」从下一本恢复（暂停在当前本处理完后生效）。
或者在资源管理器里 Ctrl 多选文件夹后拖到本页任意位置（仅 Chrome / Edge）：每个父文件夹下的子文件夹 = 一篇草稿
• 网页的「选择文件夹」窗口一次只能选一个，按 Ctrl 多选无效（浏览器限制，不是故障）。要一次加多个，只有两种办法：
　① 反复点选（任何浏览器都行）：点上面按钮选一个 → 再点、再选，全部累加到「已添加」列表。
　② 拖入多个（仅 Chrome / Edge）：在 Windows 资源管理器里按住 Ctrl 选中多个文件夹，拖到本页任意位置即可。360 / QQ / 搜狗等浏览器不支持拖入，请用办法 ①。
所有加进来的文件夹会在点一次「开始处理」后批量上传。
• 从 HandmadeV 采集下来的图片是按文章目录存放的：选最外层那个父文件夹（如 images_chart），它下面的每个子文件夹就是一篇文章，标题取子文件夹名。
• 如果直接选中某一个文章目录（里面直接是图片、没有再下一层），就只生成 1 篇。
• 只上传 .webp / .jpg / .jpeg / .png / .gif / .avif 图片，其它文件（txt、json、desktop.ini 等）自动跳过；同一文件夹内按文件名自然排序（1, 2, 10 而不是 1, 10, 2），原图直传，不做任何切片或重新编码，第一张自动作封面。
• 文件夹名里的批次编号（001-xxx 或 xxx-001）会在生成标题与 slug 时自动去掉：发布出去的标题不带编号，编号只用于你本地按批上传时区分；同一篇重复上传也只会覆盖同一份草稿，不会多出一篇。
• 每个文件夹最多 200 张、单张 ≤ 20MB；超出的图片跳过并记录。上传仍计入下方 1000 张/小时配额。
图床套餐提示：目前图床套餐，上传限制 1000 张 / 小时。 PDF 模式每页约产生 1 张图（长页自动切片成多张）；文件夹模式每张图片算 1 张。超出限额后该篇会标记为不完整、提交时自动跳过。 下方实时统计：同一小时内多次批量上传会累计，满 1 小时自动从 0 重新计数；接近上限时自动暂停，无需自己估算。
