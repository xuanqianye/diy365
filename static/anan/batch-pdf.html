PDF 批量发布图解

一次选多个 PDF，每个 PDF 生成一篇草稿（图片来自 PDF 逐页裁剪并上传图床）。提交后请到 草稿管理页 /anan/drafts.html 点「发布」或「全部发布」即可上线（推荐，直接改文件更可靠）。也可在 Decap 后台取消「草稿（不发布）」勾选，但后台的「已发布」状态可能显示不准。

统一设置（应用到每篇）
• 标题自动取 PDF 文件名（去扩展名，下划线/连字符转空格，保留序号），例如 0012_sunflower.pdf → 0012 sunflower。
• 分类 / 标签建议填与「分类管理 / 标签管理」里已有的名称，前台才会出现对应聚合页；填新名称 Hugo 也会自动建页。
PDF 限制：每本 ≤ 100MB、≤ 100 页；长页会自动切片成多张图。每个 PDF 会变成若干张步骤图，第一张自动作封面。 处理在浏览器本地完成，可能耗时较久（页数多时请耐心等待，不要关闭页面）。可点「暂停」暂停当前批次，再点「继续」从下一本恢复（暂停在当前本处理完后生效）。
图床套餐提示：目前图床套餐，上传限制 1000 张 / 小时。 每页 PDF 约产生 1 张图（长页会自动切片成多张）；超出限额后上传会失败，该本 PDF 会标记为失败且不会自动重试。 下方实时统计：同一小时内多次批量上传会累计，满 1 小时自动从 0 重新计数；接近上限时自动暂停，无需自己估算。
